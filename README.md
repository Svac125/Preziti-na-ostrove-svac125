# 🏝️ Příručka přežití na pustém ostrově

> *Protože dovolená bez zpáteční letenky je pořád dovolená… jen trochu delší.*

## Úvod: Vítej na svém novém domově

Probudil ses na pláži. Žádný telefon, žádný internet, žádná káva.  
Jen ty, písek, a **jeden jediný kokos**.

Tato příručka ti pomůže přežít první dny, týdny a (pokud budeš šikovný) i měsíce na ostrově.

---

## 1. Základní pravidla přežití

### 1.1 Hierarchie potřeb na ostrově

1. **Pitná voda**
2. Přístřešek
3. Jídlo
4. Oheň
5. Záchrana (volitelné)

### 1.2 Denní checklist přeživšího

- [x] Najít zdroj pitné vody
- [x] Postavit základní přístřešek
- [ ] Ulovit něco k snědku
- [ ] Rozdělat oheň bez zapalovače
- [x] Prohledat pláž pro užitečné trosky
- [ ] Vyslat signál pro záchranu
- [ ] Nevzdat se

---

## 2. Výbava, kterou si (ne)vezmeš

| Položka                | Užitečnost     | Realita na ostrově                      |
|------------------------|----------------|-----------------------------------------|
| Nůž                    | **Kritická**   | Bez něj jsi mrtvý                       |
| Lano                   | Velmi vysoká   | Na všechno                              |
| Zapalovač              | Vysoká         | Až dojde plyn, jsi v prdeli             |
| Mobilní telefon        | ~~Vysoká~~ Nulová | Funguje maximálně jako zrcadlo         |
| Sluneční brýle         | Střední        | Vypadáš cool, ale nic ti nepomůžou      |
| Kniha „Jak přežít“     | Nízká          | Už ji máš v hlavě (tuhle příručku)      |
